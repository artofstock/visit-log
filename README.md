# 방문일지 (PWA)

체납자 방문 명단 검색·메모 앱입니다. 명단 데이터는 **기기(브라우저) 안에만** 저장되고, 이 저장소에는 올라가지 않습니다.

## 파일
- `index.html` : 앱 본체
- `manifest.webmanifest`, `icons/` : 홈 화면 설치용
- `sw.js` : 오프라인 실행용

## GitHub Pages로 올리기
1. GitHub에서 저장소를 만듭니다(예: `visit-log`). 기존 저장소에 덮어써도 됩니다.
2. **Add file → Upload files**로 이 폴더 안의 파일을 **폴더째(index.html이 맨 위에 오도록)** 올리고 Commit 합니다.
3. **Settings → Pages → Branch: main, 폴더: / (root) → Save**
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 으로 열립니다.

## 휴대폰/태블릿에 설치
1. 크롬에서 위 주소를 엽니다.
2. 메뉴(⋮) → **홈 화면에 추가(앱 설치)**
3. 처음 한 번 열어 두면 이후에는 인터넷이 없어도 실행됩니다.
4. 설치한 앱에서 엑셀 불러오기 또는 백업 파일 복원으로 명단을 넣으세요.

## 새 버전 올리기
`index.html`을 바꿔 올릴 때 `sw.js` 첫 줄의 `visitlog-v1` 숫자를 올리세요(v2, v3…). 인터넷이 되는 상태에서 앱을 열면 새 버전으로 바뀝니다.

## 주의
- **명단 엑셀이나 백업 JSON 파일은 절대 저장소에 올리지 마세요.** 개인정보가 들어 있습니다.
- 데이터는 기기마다, 열어 쓰는 주소마다 따로 저장됩니다. 설치한 앱으로 옮길 때는 먼저 💾 저장으로 백업을 받아 두었다가 복원하세요.
- 브라우저의 "사이트 데이터 삭제"를 하면 저장된 명단도 지워집니다. 정기적으로 💾 저장하세요.
